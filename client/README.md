# AI Career Recommender — Client

A modern React 18 single-page application built with **Vite**, **Material UI (MUI v5)**, **React Router v6**, and **Axios**.

---

## Prerequisites
- Node.js 20+
- Backend server running on `http://localhost:5000`
- ML service running on `http://localhost:8000`

---

## Getting Started

1. Navigate to the client directory:
   ```bash
   cd client
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure environment:
   ```bash
   copy .env.example .env
   ```

4. Start development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit:
   `http://localhost:5173`

---

## Phase 5A Scope Note
Phase 5A establishes the application scaffold, global theme, responsive layout shell, and authenticated routing flow (Register, Login, Session Persistence, and Route Protection). The interactive recommendation form, career analysis charts, and historical reports are delivered in Phases 5B and 5C.
